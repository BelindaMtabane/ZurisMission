Place transparent PNG obstacle images in this folder.
In Unity, set each image Texture Type to "Sprite (2D and UI)".

Required filenames:
rock.png
mud.png
cactus.png
cactus_wall.png
warthog.png
log.png
snake.png
poison.png
monster.png
sand_pit.png
heat_wave.png
acid.png
lightning.png
tree.png
wolf.png

Recommended: square transparent PNGs, 256x256 or 512x512.
